### 🔭 Recent Works
- **VSCE-EL** — M.Tech thesis: visually-driven multimodal entity linking over 90K+ entities. Five-stage pipeline (hybrid retrieval → cross-encoder reranking → QLoRA-tuned Qwen2-7B selection). **94.75% Top-1 on WikiMEL**, 93.38% on Richpedia, 93.12% on Wikidiverse.
- **DataPilot** — Multi-agent AI data analyst. Ask questions in plain English; six LangGraph agents plan, write SQL/Python, validate, chart and explain, through three MCP tool servers. Read-only SQL enforced server-side, with 7/7 malicious queries blocked in direct guardrail tests.
- **WebRAG** — Local-first RAG for the web: Chrome extension + FastAPI backend, hybrid BM25 + dense retrieval fused with Reciprocal Rank Fusion, local LLM reranking via Ollama, shipped with Docker Compose. No cloud APIs.
- **AskMyDoc** — RAG system over research papers. Hybrid BM25 + dense retrieval + SBERT reranking, citation-grounded generation, **85%+ RAGAS faithfulness**.
